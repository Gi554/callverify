# Présentation publique Orvia

Vitrine HTML/CSS centrée sur l’activité commerciale Assurance. Le fichier CSS dédié ne modifie pas les pages de confidentialité/conditions. Les données de l’aperçu sont illustratives. Les offres sont indicatives sur devis et les liens contact sont des mailto ; aucun moteur de facturation ni formulaire distant.

Référence de direction visuelle : https://thepatchsystem.com/ (consultée le 25 octobre 2026). Textes, composition et illustrations sont créés pour Orvia. Aucun visuel Patch ou police PP Right propriétaire n’est embarqué. Aucune conformité pixel par pixel n’est revendiquée sans comparaison visuelle.

Polices libres locales :
- Barlow Condensed ExtraBold : https://github.com/google/fonts/tree/main/ofl/barlowcondensed
- Archivo variable : https://github.com/google/fonts/tree/main/ofl/archivo

Licences OFL complètes conservées dans fonts/. Les polices ne sont pas chargées depuis Google Fonts à l’exécution.

Le JavaScript est une amélioration progressive : fermeture du menu après choix ou Échap, animations non essentielles uniquement si le mouvement réduit est désactivé. Aucun élément ne reste masqué si le JavaScript échoue.
